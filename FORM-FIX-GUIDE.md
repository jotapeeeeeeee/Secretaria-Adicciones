## 🚨 REQUIRED: Configure Gmail App Password

The form will NOT work until you configure a real Gmail App Password.

### Steps:

1. **Enable 2-Factor Authentication** in your Google account:
   - Go to: https://myaccount.google.com/security
   - Enable "2-Step Verification"

2. **Generate an App Password**:
   - Go to: https://myaccount.google.com/apppasswords
   - Select "Mail" and your device
   - Click "Generate"
   - **Copy the 16-character password** (no spaces)

3. **Configure on Render** (see next section)

## 🔍 Debug Tips

If it still fails after configuration:

1. **Check Render logs**:
   - Dashboard → Your service → **Logs** tab
   - Look for error messages

2. **Test the health endpoint**:
   ```
   https://secretaria-adicciones.onrender.com/api/health
   ```
   Should return: `{"ok": true, "service": "secretaria-adicciones-backend"}`

3. **Check browser console** (F12):
   - Look for CORS errors
   - Look for network errors
   - Check the API response when form fails

4. **Common issues**:
   - ❌ SMTP password is still the placeholder
   - ❌ `FRONTEND_ORIGIN` doesn't match where you're accessing the site from
   - ❌ Render service is sleeping (free tier - wait 30-60 seconds for first request)
