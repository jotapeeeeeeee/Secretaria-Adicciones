# 🏛️ Secretaría de Adicciones - Rediseño Web

## 📖 Descripción
Rediseño y refactorización de la página web de una secretaría gubernamental de adicciones como proyecto personal. El objetivo fue mejorar la **accesibilidad**, la **experiencia de usuario (UX)** y la **estética visual**, manteniendo la información oficial.

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3** (Flexbox, Grid, animaciones)
- **Diseño Responsive** (Mobile First)

## 📂 Estructura del Repositorio
- `index.html`: Página principal con información de contacto y servicios.
- `styles.css`: Hoja de estilos con variables CSS y diseño modular.
- `assets/`: Imágenes optimizadas y recursos gráficos.

## 🚀 Instrucciones de Ejecución
1. Clonar el repositorio.
2. Abrir `index.html` en cualquier navegador.

## 📊 Comparativa Antes / Después
- **Antes**: Navegación confusa, colores poco contrastados, no responsive.
- **Después**: Menú claro, paleta de colores accesible, adaptación a dispositivos móviles.

## 🔮 Mejoras futuras
- Agregar formulario de contacto funcional (con backend).
- Incorporar un mapa interactivo con ubicación de centros de atención.
- Implementar modo oscuro y alto contraste para accesibilidad.
